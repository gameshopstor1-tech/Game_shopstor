# GAME SHOP - GitHub Pages

## راه‌اندازی
1. سه فایل `index.html`, `style.css`, `script.js` را در یک Repository در GitHub آپلود کن.
2. از Settings → Pages، گزینه Deploy from a branch را انتخاب کن و branch اصلی را روی `/ (root)` بگذار.
3. چند دقیقه بعد آدرس GitHub Pages نمایش داده می‌شود.

این نسخه فرانت‌اند است؛ پرداخت آنلاین واقعی و پنل مدیریت مرکزی هنوز به بک‌اند/درگاه نیاز دارد.

## ویژگی‌های اضافه‌شده

### مشاهده محصولات بدون ثبت‌نام
- همه کاربران می‌توانند محصولات را بدون ورود ببینند.
- برای افزودن به سبد و خرید، ورود/ثبت‌نام لازم است.

### ورود ساده
- فقط وارد کردن **نام** + تیک **من ربات نیستم** (اجباری).
- قابلیت رمز عبور حذف شده است.
- متن توجه در صفحه ورود:
  > توجه: سفارش شما با اسمی که در سایت وارد می‌کنید ثبت می‌شود.

### ثبت‌نام اجباری برای خرید
- نام و نام خانوادگی
- آیدی تلگرام یا شماره تلفن
- تیک من ربات نیستم

هر کاربر یک **کد اختصاصی کاربری** مثل `USR-XXXXX-XXXX` دریافت می‌کند.

### خرید چندتایی از یک محصول
- می‌توانید چند بار از یک محصول بخرید (مثلاً ۲ بار ۸۰ CP).
- در سبد با دکمه‌های + و − تعداد را تغییر دهید.

### صفحه پرداخت و انتخاب روش پرداخت
- کارت به کارت
- پرداخت از طریق تلگرام
- سایر روش‌ها

کد اختصاصی سفارش **اجباری** است و قبل از ثبت نهایی ساخته می‌شود.

### کد اختصاصی سفارش و پیگیری
- هر سفارش یک کد یکتا مثل `GS-ABC123-X7K2` دارد.
- از منوی «پیگیری سفارش» می‌توانید با کد، وضعیت را ببینید.
- کد برای ثبت سفارش در سایت و ارسال به تلگرام الزامی است.

### پنل مالک

- در پنل:
  - لیست خلاصه کاربران ثبت‌نام‌شده + **حذف کاربر توسط مالک**
  - لیست سفارش‌ها با کد اختصاصی
  - **تب همکاران:** افزودن همکار (نام، نام کاربری، رمز)، مشاهده لیست و **حذف همکار** — مالک دسترسی کامل روی همکاران دارد

### پنل همکار
- مالک از تب «همکاران» همکار جدید می‌سازد.
- ورود همکار از لینک «ورود همکار» در صفحه ورود (با نام کاربری و رمزی که مالک تعریف کرده).
- همکار فقط می‌تواند کاربران و سفارش‌ها را **مشاهده** کند (بدون حذف کاربر یا مدیریت همکاران).

### ورود همکار از چند دستگاه / چند گوشی
چون سایت روی GitHub Pages است و داده‌ها در localStorage هر مرورگر جدا ذخیره می‌شوند، برای اینکه همکار بتواند با همان نام کاربری و رمز در گوشی‌ها یا دستگاه‌های دیگر وارد شود:
1. مالک در پنل → تب همکاران، روی دکمه **«کپی کد اشتراک (برای گوشی‌های دیگر)»** کلیک می‌کند.
2. کد (شروع با `GSCOLLAB-`) را برای همکار می‌فرستد (تلگرام، پیامک و غیره).
3. همکار در دستگاه جدید، صفحه ورود همکار را باز می‌کند، کد را در بخش پایین مودال وارد کرده و «وارد کردن کد در این دستگاه» را می‌زند.
4. سپس با همان نام کاربری و رمز که مالک داده وارد می‌شود.

این کار فقط یک‌بار در هر دستگاه لازم است؛ بعد از آن ورود فقط با نام کاربری و رمز انجام می‌شود.
